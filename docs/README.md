# docs/ — Documentación del proyecto Warengine

Esta carpeta contiene toda la documentación oficial del proyecto.

**Qué va aquí:** SRS (PDF), script SQL de la base de datos, diagramas ER,
decisiones de arquitectura (ADR) y el archivo de contexto para el asistente IA.

**Qué NO va aquí:** código fuente, dependencias, configuraciones de herramientas,
archivos generados automáticamente ni documentación de APIs (esa va en `BACK/`).
